# Portfolio – Rijaniaina Andriamandimby

Next.js 16 · React 19 · Tailwind CSS 4 · TypeScript · EN / FR / DE / ES · thème clair/sombre

    npm install
    npm run dev          # développement
    npm run check        # typage + lint + build + vérifications avant déploiement
    npm run start        # après `npm run build`

Documentation (dossier `docs/`) :
- `TECHNICAL_SHEET.md` – architecture, recettes de modification, animations, performance, SEO
- `CHANGE_SHEET_TEMPLATE.md` / `CHANGELOG.md` – fiche à remplir à chaque modification
- `PROD_CHECKLIST.md` – à vérifier avant la mise en production

Copier `.env.example` vers `.env.local` et renseigner `NEXT_PUBLIC_SITE_URL`.
